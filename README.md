# Weather Dashboard

An internationalized weather dashboard built with [gt-next](https://generaltranslation.com/docs/next) and Next.js, demonstrating locale-aware number formatting, dates, and translated weather content using `<T>`, `<Num>`, and `<DateTime>`.

**[Live Demo →](https://weather-dashboard.generaltranslation.dev)**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and switch locales to see formatting change.
